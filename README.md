# Defenders of the Data

*Defend your data. Fight back against scams.*

A tower defense game about staying safe online, made for the Girls Who Code HHS Hackathon 2026.

Hackers, phishers and malware are marching toward your Data Core. Stop them by building towers, and every tower is a real online safety habit: checking links, strong passwords, 2-step verification, software updates and privacy settings. Match the right defense to the right threat, and learn how to protect yourself in real life along the way.

## How to play

1. **Unlock towers** by passing a quick safety challenge. Each tower is a real habit.
2. **Build towers** next to the path to stop threats before they reach your Data Core.
3. **Scan threats.** They arrive as mystery messages. Identify each one for double damage.
4. **Real or Scam?** Between waves, spot the scams to earn bytes.
5. **Answer live DMs** that pop up mid-wave. A safe reply gives an Overclock boost, and a risky one lets more threats in.
6. **Upgrade towers** by answering deeper questions, and build answer streaks to charge the 💥 Firewall Blast.
7. **Beat the bosses.** Every 10th wave is a **Ransomware Boss** that locks your towers, and you restore them by answering questions about backups.
8. **Remember your password!** The practice password you make for the 2FA Lock comes back: every few waves, a surprise login check asks for it plus a 2-step code.
9. **Two modes.** **Levels:** clear 100 levels (a boss every 10) on the 🗺️ Level Map. To jump ahead, pass a **Security Clearance** test: threat intel, intercepted messages, fact or myth, link scanner, repair the rule and reconnect the wires, with 3 firewall shields. **Endless:** the waves never stop, so beat your best.
10. **Study** flashcards, review what you missed, and collect 🏅 badges.

Questions get harder as the waves go up: easy, then medium, then hard.

Progress, badges and sound settings are saved in the browser on the computer you play on.

Keys: 1-4 towers, S sell, Space start wave, B blast, L study, V level map, P pause, F speed, M mute. Works with a mouse or keyboard (Tab, Enter, Esc).

## Run it locally

No install needed. Open `index.html` in a browser, or serve the folder:

```
npx serve .
```

## Built with

HTML, CSS and JavaScript (Canvas), no game engine.
