# Defenders of the Data

*Defend your data. Fight back against scams.*

A tower defense game about staying safe online, made for the Girls Who Code HHS Hackathon 2026.

Hackers, phishers and malware are marching toward your Data Core. Stop them by building towers, and every tower is a real online safety habit: checking links, strong passwords, 2-step verification, software updates and privacy settings. Match the right defense to the right threat, and learn how to protect yourself in real life along the way.

## How to play

1. Threats travel down the path toward your Data Core.
2. Pick a tower, then click an empty spot next to the path to place it.
3. Each tower works best against certain threats, so choose wisely.
4. Survive every wave to win the level.

Works with a mouse or keyboard (Tab, Enter, Esc).

## Run it locally

No install needed. Open `index.html` in a browser, or serve the folder:

```
npx serve .
```

## Built with

HTML, CSS and JavaScript (Canvas), no game engine.
